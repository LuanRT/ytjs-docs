# 介绍

YouTube.js 是 YouTube 私有 API（称为 "InnerTube"）的 JavaScript 客户端。它允许你以编程方式与 YouTube 交互，提供对视频、评论、直播聊天、流媒体数据等的访问。支持 Node.js、Deno、浏览器以及任何其他现代 JavaScript 环境。
